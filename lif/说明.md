# LIF 神经元复现说明

## 在算什么

膜电位 `U` 每步累积输入 `X`、同时缓慢泄漏；超过阈值发一个脉冲并复位。

离散写法（`lif.py` 里就是这个）：

    U[t] = U[t-1] + (X[t] - U[t-1]) / tau

## 四种情况

| 组合 | 现象 | 原因 |
|---|---|---|
| decay_input=True, reset=0 | 几乎不放电 | 稳态 ≈ 输入 ≈ 阈值 1.0，够不到 |
| decay_input=True, reset=0.2 | 规律放电 | 复位点抬高，稳态整体上移 0.2 |
| decay_input=False, reset=0 | 放电很密 | 输入不衰减，稳态 = tau·X |
| decay_input=False, reset=0.2 | 最密 | 以上两者叠加 |

## 改什么能看出区别

- `tau` 改成 1.0 / 5.0：tau 越大越"迟钝"
- `X = torch.ones(T) * 0.4`：换成恒定输入，脉冲变等间隔

## 结论

- 神经元的行为由三个旋钮决定：时间常数 tau、阈值、复位值
- 「放电频率」编码了输入强度——这是 SNN 的速率编码（rate coding）的雏形
